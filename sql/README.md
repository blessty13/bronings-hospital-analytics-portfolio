# Bronings Hospital Analytics – SQL Investigation

## Project Overview

This project demonstrates how SQL was used to investigate operational challenges within a simulated NHS hospital. Using Microsoft SQL Server and T-SQL, I analysed validated healthcare datasets to answer twelve business questions covering patient pathways, waiting times, consultant performance, workforce staffing, theatre utilisation, and data quality.

The investigation produced reproducible, commented SQL queries that support evidence-based decision-making and provide the foundation for subsequent Power BI dashboards and Snowflake reporting.
